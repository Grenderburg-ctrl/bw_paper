# Реестр МИ Росздравнадзора: наборы для ИЛ-6, ИЛ-8, ИЛ-10, NT-proBNP

- `RosZdravNadzor_RU_parser_IL_NTproBNP.ipynb` — ноутбук для Google Colab (запустить все ячейки).
- `rzn_markers_parser.py` — тот же код одним скриптом (`python rzn_markers_parser.py`).
- `RZN_IL6_IL8_IL10_NTproBNP.xlsx` — результат запуска 2026-11-06.

Скрипт берёт данные из JSON API виджета реестра (`elk.roszdravnadzor.gov.ru`),
а не из MHTML-страниц: поиск `filter-public` по всем страницам со статусом «Действует»,
затем карточка РУ и список моделей для каждой найденной записи.

Колонка «Подходит»:
- **да** — найден маркер, количественный набор/калибратор/контроль, в описании указаны кровь/сыворотка/плазма;
- **проверить по инструкции** — маркер найден, но образец не указан в реестре
  (типично для многопозиционных РУ к анализаторам), либо тест качественный/полуколичественный,
  либо мультиплекс CBA на проточном цитометре;
- **нет** — только BNP / другие IL, ПЦР/генотипирование, ИГХ, внутриклеточная цитометрия, не кровь.

Лист «Подходящие» = «да» + «проверить»; отдельные листы по каждому маркеру.
